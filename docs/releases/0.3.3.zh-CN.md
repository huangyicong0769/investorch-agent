# InvestOrch Agent 0.3.3

[English](0.3.3.md)

- 修改 OpenAI 官方 API 和 ChatGPT 连接中 GPT-6.2 的指令位置，将稳定 Agent 指令移至首条 `developer` 消息，使会话追加历史时仍可复用这段请求前缀。
- 修复 ChatGPT 回传 SDK 解析字段导致的请求错误，使本地工具调用和结构化回复可跨轮回放。
- 修改 DeepSeek Flash 的工具图片处理，使开启思考的请求能在原工具结果中保留图片，并同时使用原生搜索、URL 阅读、自动标题和高等级内容审核。
- 修复 DeepSeek 流式请求的终止用量统计，使拒答或失败响应的基础 Token 按请求计一次。OpenAI Agents SDK 已升级至 0.25.0，OpenAI Python SDK 已升级至 3.58.0。
