# InvestOrch Agent 0.3.3

[English](0.3.3.md)

- 修改 Session 初始化，将固定 System Prompt 保存为首条 `developer` 消息，使其进入 GPT-6.2 可缓存的请求前缀。Compact 只压缩这条消息之后的历史。**破坏性变更。** 已有实例需执行[一次性 Session 迁移](../Upgrade.zh-CN.md#033-session-历史迁移)。
- 修复同一连接跨 Run 时的历史回放，使 Main 保留该连接产出的推理项和响应条目 ID。来自其他连接或来源未知的条目只在请求副本中做移植处理。
- 修复 ChatGPT 回传 SDK 解析字段导致的请求错误，使本地工具调用和结构化回复可跨轮回放。
- 修改 DeepSeek Flash 的工具图片处理，使开启思考的请求能在原工具结果中保留图片，并同时使用原生搜索、URL 阅读、自动标题和高等级内容审核。
- 修复 DeepSeek 流式请求的终止用量统计，使拒答或失败响应的基础 Token 按请求计一次。
- 升级 OpenAI Agents SDK 至 0.25.0、OpenAI Python SDK 至 3.58.0。
