# InvestOrch Agent 0.3.3

[简体中文](0.3.3.zh-CN.md)

- Official OpenAI and ChatGPT connections send stable GPT-6.2 Agent instructions as the first developer message. This keeps the instructions in the reusable prompt prefix as conversation history grows.
- ChatGPT can replay local tool calls and structured replies across turns. The adapter omits SDK parsing fields that the Responses API rejects.
- With thinking enabled, DeepSeek Flash can use native search, URL reading, titles, and high content safety review alongside images from local function tools. The images stay in their original tool results.
- Updated OpenAI Agents SDK to 0.25.0 and OpenAI Python SDK to 3.58.0. DeepSeek responses that end in a refusal or failure count their base token usage once.
