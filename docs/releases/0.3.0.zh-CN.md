# InvestOrch Agent 0.3.0

[English](0.3.0.md)

InvestOrch Agent 0.3.0 增加多代理编排、可复用模型连接与 ChatGPT 授权、按 Session 选模、持续上下文管理，并改进运行诊断。

## 多代理编排

0.3.0 将任务委派、递归子 Session、跨 Session 通信、结果读取与 Web 任务管理串联起来。Agent 可拆分工作、协调后续行动，并读取子任务结果进行整合。

Agent 可通过 `list_sessions` 查找 Session、`read_session` 读取历史，以及通过 `send_message` 发送经审批的文字或图片。消息携带发送来源，进入目标 Session 的正常用户输入流程，沿用普通审批规则。回执仅表示接纳，不表示完成；Queue 仍只存在于当前进程。

`spawn_agent` 创建拥有独立历史和审批的普通子 Session。子 Session 可递归派生，共享全局 Run 上限，并获得一次性的 Portfolio 关联快照。Spawn 默认继承 parent 的活动模型，也可显式覆盖。Web 展示父子关系、实时任务状态与导航。Delete/Clear 检查完整后代范围，活动任务或独立 Fork 引用会阻止删除。

## 模型连接与 ChatGPT

配置拆分为可复用的 `models.<connection>` 和五个 `agents.<role>` 默认值。连接可使用 OpenAI 兼容 API Key 或官方本地 ChatGPT 授权。ChatGPT 按账号获取模型目录，按需刷新凭据；登录、退出和刷新无需重启 Host。用量限制或缺少计划访问权限不会触发静默切换账号或付费 API。

Web Setup 和 Settings 分别管理连接与 Agent 默认值。**Continue with ChatGPT** 打开浏览器授权；具备资格的账号须明确允许计划用量。纯 ChatGPT 配置无需 API Key。API Key 和 OAuth Token 私密保存在 Local TOML 中。连接和 Agent 默认值修改需重启；可选连接测试会发送一次小型真实请求。完整 API 与多账号示例见[配置指南](../Configuration.zh-CN.md)。

## 按 Session 选模

输入框右下的模型/推理强度入口及 TUI/plain 的 `/model`、`/effort` 编辑选中 Session 的下次 Run Draft。下一次接纳的 Run 将连接、真实模型、effort 和正整数窗口冻结并持久化，活动 Run 保持原选择。Queue 晋升时解析最新 Draft；Steer 保持活动模型。Fork 保留持久选择，将未提交选择复制为 Draft。退出进程会丢失未使用的 Draft。

前置压缩在 Main 推理前检查 continuation 和新输入是否适配本 Run 窗口，即使关闭自动压缩也会执行。开启自动压缩后，还会在工具调用之间检查上下文。失败或仍超预算会阻止 Main。压缩保留完整 Journal、未完成工作，以及继续执行所需的工具调用/结果关联。每次新 Run 都会在旧历史的请求副本中剔除不透明 reasoning 与 Provider response-item ID，存储原件不变。同连接跨 Run 也适用，可能影响连续性或缓存效率。

## 运行反馈与 Web 工作流

- 在请求完成时显示 Main 与辅助角色用量；后续失败或取消时，仍计入已经消耗的前置用量。Provider 提供推理摘要时，将其用于活动标题。
- 将可操作、脱敏的 Run 失败原因保留在对话历史中。审批拒绝意见返回 Main Agent，供其修正下一步行动。
- 刷新、调整窗口和重连时保留活动审批、草稿与导航状态；System Status 可查看孤立后台进程，并区分已诊断问题与未检查连接。
- 隔离 MCP 连接失败，避免其直接终止 Agent Run；保留安全的初始化原因供诊断。

## 策略工作流与依赖

内置 Skill 明确专用工具链、Artifact 交接和验证步骤。RQAlpha 研究使用原生数据检查/回测工具，支持带类型的单次执行参数、串行引擎执行、原生日志与可操作的引擎拒绝反馈。Portfolio 写入要求读回 Ledger；QMT 产物仍由人审查和部署。

更新 Python、Web、构建依赖及 lockfile，包括 OpenAI Agents SDK 0.24.0、FastAPI 0.161.1、RQAlpha 6.4.2、可选 CNEquity 0.18.0 和 uv_build 0.13.5。源码安装使用已提交的 lockfile；修改前端后须重建生产 Web bundle 再打包。

## 安装与分发

0.3.0 通过 PyPI 提供 wheel 与源码包，并提供 GitHub 发行包和 SHA-256 checksum。源码安装与校验发行 wheel 的步骤见 [README](../../README.zh-CN.md#安装)。

使用 uv 安装：

```sh
uv tool install --python 3.12 investorch==0.3.0
```

仍要求 Python 3.12–3.14（`>=3.12,<3.15`）。

维护者的 GitHub 与 PyPI 发布步骤见[发布指引](../Publishing.md)。

## 不兼容升级

旧 `models.<role>` TOML 不兼容。须将 Endpoint/Key 字段转为命名连接，再把模型名称、effort、窗口移至 `agents.<role>` 并增加连接引用。不提供自动 TOML 迁移，也不引入 `config_version`。已有 Session SQLite 元数据通过正常初始化增加可空模型字段；旧版未绑定 Session 在下一次 Run 使用新的 Main 默认值。

升级前停止全部写入进程，保存旧环境与完整 Root，记录旧有效角色设置，先离线转换副本，再验证就绪状态与数据。回滚须恢复完整升级前 Root 和旧环境。请按[升级说明](../Upgrade.zh-CN.md)操作，勿直接让新代码启动未转换的原始 Root。

受管内置 Skill 包含更新后的配置与策略指导。已有实例仅通过显式 `investorch --update` 后重启采用随包内容；自定义 Skill、Memory 和启用状态沿用既有更新语义。
