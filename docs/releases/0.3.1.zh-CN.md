# InvestOrch Agent 0.3.1

[English](0.3.1.md)

新的 DeepSeek 连接默认使用 `deepseek-flash`。Flash 可在推理中搜索和阅读 URL，界面显示可点击的来源，Run 日志记录服务端返回的计费用量。可从模型菜单控制下一次 Run 的联网。未命名 Session 会在首个有效标题到达时立即保存并更新界面。

Python 调用方可以使用 Files、文档解析、OCR、ASR 和两种 TTS 接口，也可以为 Flash 文本请求启用内容审核。 [能力与配置](../Configuration.zh-CN.md#deepseek-flash)

DeepSeek 要求开启思考才能在同一请求中同时使用原生能力和本地工具。思考关闭时保留本地工具。开启思考后可搭配原生联网、标题和显式安全审核。

已有实例启动前请移除本地 TOML 的 `[agents.title]` 表，并检查旧 Flash 模型 ID。 [从 0.3.0 升级](../Upgrade.zh-CN.md#030--031-deepseek-配置)

设置 `DEEPSEEK_API_KEY` 环境变量后，可执行真实接口验收。

```sh
uv run --locked python scripts/qualify_deepseek.py
```

验收使用合成样本，会消耗 DeepSeek API 额度，并清理已上传的样本。
