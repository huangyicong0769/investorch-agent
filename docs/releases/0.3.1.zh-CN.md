# InvestOrch Agent 0.3.1

[English](0.3.1.md)

0.3.1 接入 DeepSeek 应用 API 套件。会话支持原生联网搜索、网页读取、来源引用、计费用量和内容审核。Python 接口提供 Files 和文档解析、OCR、ASR，以及 HTTP TTS 和 WebSocket 流式合成。

新建 DeepSeek 连接默认使用 `deepseek-flash`。可从 Session 模型菜单开关下一次 Run 的联网。 [能力与配置](../Configuration.zh-CN.md#deepseek-flash)

Sign in with ChatGPT 的 Main 也支持原生联网搜索，界面显示实时进度和来源链接。 [ChatGPT 配置](../Configuration.zh-CN.md#chatgpt-多账号与混合连接)

未命名 Session 收到主模型的首个有效标题时立即更新。主回答完成后若 Session 仍无标题，Title Agent 继续负责命名。

Web 的 Session 菜单可以复制完整 Session ID。

Main 提示词引导模型限制 MCP 数据查询范围，将批量数据写入工作区文件后再处理。

## 修复

- 修复 Run 自动压缩后继续执行时 DeepSeek 返回 HTTP 400 的问题。
- 修复大型工具清单导致上下文估算过高、短输入也被拦截的问题。
- 修复 Web 对话里同一 Run 失败原因显示两次的问题。
- 修复 Compact 保留超出模型输入预算的签名联网历史的问题。
- 修复 DeepSeek Pro 打开联网开关后原生搜索未启用的问题。
- 修复 DeepSeek 后续请求丢失标准联网调用 ID 的问题。
- 修复 DeepSeek 仅在最终响应返回引用时界面遗漏引用的问题。
- 修复 DeepSeek 关闭思考时同一请求同时声明本地工具与不兼容原生能力的问题。
- 修复 Flash 开启原生搜索或网页读取时拒绝工具返回图片的问题。请求保留图片，并暂停与图片不兼容的工具。
- 修复 Web 连接配置界面误导用户将 API 密钥填入明文引用字段的问题。
- 修复多个新建 DeepSeek 连接共用密钥引用、凭据可能互相覆盖的问题。
- 修复 Web 模型选择器中较长的模型列表遮挡其他连接的问题。
- 修复截断的 WAV 文件在语音转写上传前通过校验的问题。
