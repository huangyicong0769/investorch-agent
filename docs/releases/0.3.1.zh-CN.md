# InvestOrch Agent 0.3.1

[English](0.3.1.md)

0.3.1 接入 DeepSeek 应用 API 套件。会话支持原生联网搜索、网页读取、来源引用、计费用量和内容审核。Python 接口提供 Files 和文档解析、OCR、ASR，以及 HTTP TTS 和 WebSocket 流式合成。

新建 DeepSeek 连接默认使用 `deepseek-flash`。可从 Session 模型菜单开关下一次 Run 的联网。 [能力与配置](../Configuration.zh-CN.md#deepseek-flash)

Sign in with ChatGPT 的 Main 也支持原生联网搜索，界面显示实时进度和来源链接。 [ChatGPT 配置](../Configuration.zh-CN.md#chatgpt-多账号与混合连接)

未命名 Session 收到主模型的首个有效标题时立即更新。主回答完成后若 Session 仍无标题，Title Agent 继续负责命名。
