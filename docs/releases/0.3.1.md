# InvestOrch Agent 0.3.1

[简体中文](0.3.1.zh-CN.md)

New DeepSeek connections default to `deepseek-flash`. Flash can search and read URLs during inference, show clickable sources, and leave billed usage in the Run journal. The model menu controls web access for the next Run. The first native turn title is saved as soon as it arrives in an unnamed Session.

Files, document parsing, OCR, ASR and both TTS endpoints are available to Python callers. Flash text requests can enable content review. See the [capability and configuration guide](../Configuration.md#deepseek-flash).

DeepSeek requires thinking for native features in requests with local tools. When thinking is off, InvestOrch keeps the local tools. Enable thinking to use them alongside native web access, title generation or explicit safety review.

Existing installations can keep the legacy `[agents.title]` table, which the new version ignores. Inspect model IDs during the upgrade. [Upgrade from 0.3.0](../Upgrade.md#030--031-deepseek-configuration)

Maintainers can run the live integration checks with `DEEPSEEK_API_KEY` set in the environment.

```sh
uv run --locked python scripts/qualify_deepseek.py
```

The checks use synthetic inputs, consume DeepSeek API quota and clean up the uploaded fixtures.
