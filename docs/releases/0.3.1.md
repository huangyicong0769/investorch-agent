# InvestOrch Agent 0.3.1

[简体中文](0.3.1.zh-CN.md)

0.3.1 integrates the DeepSeek application API suite. Sessions support native web search, URL reading, source citations, billed usage and content safety review. Python callers can use Files and document parsing, OCR, ASR, HTTP TTS, and WebSocket streaming TTS.

New DeepSeek connections default to `deepseek-flash`. Use the Session model menu to control web access for the next Run. [Capabilities and configuration](../Configuration.md#deepseek-flash)

Sign in with ChatGPT also enables native Web Search for Main, with live progress and source links. [ChatGPT configuration](../Configuration.md#chatgpt-accounts-and-multiple-connections)

An unnamed Session updates as soon as the Main model returns a usable title. The Title Agent supplies a title if the Main answer completes with the Session still unnamed.

The Web Session menu can copy the full Session ID.

Main's prompt directs it to keep MCP data queries small and process bulk data from workspace files.

## Fixes

- Fixed DeepSeek returning HTTP 400 when a Run continued after automatic compaction.
- Fixed large tool catalogs inflating the context estimate enough to block short prompts.
- Fixed Run failure reasons appearing twice in the Web conversation.
- Fixed Compact retaining signed web history that exceeded the model's input budget.
- Fixed the DeepSeek Pro web toggle failing to enable native search.
- Fixed standard web search call IDs being dropped from DeepSeek follow-up requests.
- Fixed missing citations when DeepSeek returned them only in the final response.
- Fixed DeepSeek requests combining local tools with incompatible native capabilities while thinking was off.
- Fixed Flash rejecting tool-returned images when native search or URL reading was enabled. The request keeps the images and pauses the incompatible tools.
- Fixed misleading wording in the Web connection form that led users to paste API keys into the plain-text reference field.
- Fixed new DeepSeek connections sharing a key reference and overwriting one another's credentials.
- Fixed long model lists hiding other connections in the Web model picker.
- Fixed truncated WAV files passing validation before transcription upload.
