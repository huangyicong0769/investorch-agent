# InvestOrch Agent 0.1.0

[English](0.1.0.md)

InvestOrch Agent 0.1.0 是首个公开预览版本。这是一个面向个人投资者的本地优先、human-in-the-loop 投资编排 Agent。

## 主要内容

- Web 与 Textual TUI 是基于同一 Application 与 Runtime 的一级界面。
- 持久化 Session 支持归档、恢复、稳定头部 Fork、清除、上下文压缩和不同 Session 的并发 Run。
- 通过 Steer 或 Queue 跟进正在执行的 Run，并以 manual 或模型辅助模式审批 Tool 调用。
- 使用限定在 Workspace 范围内的文件、命令执行、计算、Todo、配置和 MCP server 能力。
- 使用 RQAlpha 执行日频股票回测，并记录可复现元数据和 Workspace 相对 artifact。
- 可选安装 CNEquity 集成，使用其数据 CLI、当前 RQAlpha 覆盖层和只读 MCP server。

## 安装

运行环境需要 Python 3.12 或更高版本，以及 [uv](https://docs.astral.sh/uv/)。从本 Release 下载 wheel 和 `SHA256SUMS`，完成校验后安装：

```bash
uv tool install ./investorch-0.1.0-py3-none-any.whl
```

随包 Agent 配置使用 DeepSeek。启动界面前，需要在 `~/.investorch/investorch.toml` 的 `[secrets]` 中添加有效的 `DEEPSEEK_API_KEY`。完整的首次运行、校验和、数据维护与源码安装说明见 [README](../../README.zh-CN.md)。

## 当前范围

核心应用面向 macOS 和 Linux。0.1.0 不包含组合或账户访问、QMT Gateway、实盘交易、统一投资数据层和 Multi-Agent 编排。这些方向以及 Agent as MCP 支持见[产品路线图](../InvestOrch_Agent_Product_Roadmap.zh-CN.md)。

配置、Workspace 文件、Session、Journal、日志和 artifact 默认保存在本地。已配置的模型 endpoint 和 MCP server 会接收调用所需内容。Web server 只监听 loopback。
