# InvestOrch Agent 0.1.0

[简体中文](0.1.0.zh-CN.md)

InvestOrch Agent 0.1.0 is the first public preview of a local-first, human-in-the-loop investment orchestration Agent for an individual investor.

## Highlights

- Use the Web or Textual TUI as first-class interfaces backed by the same application and runtime.
- Keep persistent sessions with archive, restore, stable-head fork, clear, context compaction, and concurrent runs across sessions.
- Follow up on an active run through Steer or Queue, and review Tool calls through manual or model-assisted approval.
- Work with workspace-scoped files, commands, calculations, Todo state, configuration, and MCP servers.
- Run RQAlpha daily stock backtests with reproducibility metadata and workspace-relative artifacts.
- Add the optional CNEquity integration for its data CLI, the current RQAlpha overlay, and a read-only MCP server.

## Installation

Python 3.12 or newer and [uv](https://docs.astral.sh/uv/) are required. Download the wheel and `SHA256SUMS` from this Release, verify the checksum, then install:

```bash
uv tool install ./investorch-0.1.0-py3-none-any.whl
```

The bundled Agent configuration uses DeepSeek. Before starting an interface, add a valid `DEEPSEEK_API_KEY` to the `[secrets]` section of `~/.investorch/investorch.toml`. The [README](../../README.md) contains the complete first-run, checksum, data-maintenance, and source-installation instructions.

## Current scope

The core targets macOS and Linux. Version 0.1.0 does not include portfolio or account access, a QMT gateway, live trading, a unified investment data layer, or Multi-Agent orchestration. These areas and Agent-as-MCP support are covered by the [Product Roadmap](../InvestOrch_Agent_Product_Roadmap.md).

Configuration, workspace files, sessions, journals, logs, and artifacts are local by default. Configured model endpoints and MCP servers receive the content needed for their calls. The Web server listens on loopback only.
